# Inventory Management System

## About the Project

This repository contains the work completed for the Week 1 task of my Junior Java Developer internship.

The project focuses on planning and architecture design for a simple Inventory Management System intended for a small retail business.

## Week 1 – Project Planning and Architecture Design

The Week 1 work includes:

* Basic requirements of the Inventory Management System
* High-level system architecture
* Product Management module
* Stock Control module
* Order Processing module
* Reporting module
* Selected design patterns
* Proposed Java implementation
* Module interaction and pseudocode
* Design decisions and rationale
* Practicality and feasibility
* Future enhancements

## Proposed Technologies

* Java
* Spring Boot
* MySQL
* Spring Data JPA
* Maven
* REST API

## Architecture

The proposed system follows a simple layered architecture consisting of:

**Controller Layer → Service Layer → Repository Layer → Database Layer**

The detailed architecture and design are available in the Week 1 design document.

## Project Status

This repository currently contains the planning and architecture design completed for Week 1. The application implementation can be developed in later stages of the internship.
